No computador (ou num celular com teclado):

| Tecla | Ação |
|---|---|
| W ou ↑ | Andar para cima da tela |
| S ou ↓ | Andar para baixo da tela |
| A ou ← | Andar para a esquerda |
| D ou → | Andar para a direita |
| Espaço | [[controles/esquiva|Esquivar]] |
| 1, 2, 3 | Escolher o primeiro, segundo ou terceiro cartão no [[progressao/level-up]] |
| R | Trocar as ofertas do level-up |

Também é possível usar o mouse como se fosse um dedo: clique e arraste para mover.
