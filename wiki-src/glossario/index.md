---
titulo: Glossário
resumo: Termos usados no jogo e na Wiki.
---
| Termo | Significado |
|---|---|
| **Abate** | Inimigo derrotado. Aparece no topo da tela. |
| **Alcance** | Distância máxima em que a arma encontra um alvo. Veja [[melhorias/campo-de-ruptura]]. |
| **Cadência** | Velocidade de disparo. Veja [[melhorias/cadencia]]. |
| **Horda** | O grupo de inimigos que surge em volta do personagem. Veja [[combate/hordas]]. |
| **Isométrica** | Câmera vista de cima e na diagonal, sem perspectiva. |
| **Joystick flutuante** | Controle que aparece onde o dedo toca. Veja [[controles/joystick-flutuante]]. |
| **Leque** | Vários projéteis saindo juntos, com um pequeno ângulo entre eles. |
| **Level-up** | Subida de nível, com escolha de melhoria. Veja [[progressao/level-up]]. |
| **Melhoria** | Bônus escolhido a cada nível. Veja [[melhorias]]. |
| **Nível (Nv.)** | Quanto o personagem evoluiu na partida atual. |
| **Nível de uma melhoria** | Quantas vezes ela foi escolhida, por exemplo 2/10. |
| **Orbe** | Cristal de experiência deixado pelos inimigos. Veja [[progressao/orbes-de-experiencia]]. |
| **Prévia** | Versão de teste do jogo e da Wiki, criada para cada Pull Request. Veja [[desenvolvimento]]. |
| **Survivors** | Gênero de jogo de hordas com ataque automático e melhorias a cada nível. |
| **XP** | Experiência. Veja [[progressao/experiencia]]. |
| **Zona morta** | Área no centro do joystick em que movimentos pequenos são ignorados. |
