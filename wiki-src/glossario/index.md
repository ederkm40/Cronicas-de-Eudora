---
titulo: Glossário
resumo: Termos usados no jogo e na Wiki.
---
| Termo | Significado |
|---|---|
| **Abate** | Inimigo derrotado pelo jogador. |
| **Alcance** | Distância máxima em que o Raio arcano encontra um alvo. Veja [[melhorias/campo-de-ruptura]]. |
| **Aura** | Área ao redor do personagem que causa dano em pulsos. Veja [[armas/aura-de-brasas]]. |
| **Cadência** | Velocidade de disparo ou frequência de pulsos. Veja [[melhorias/cadencia]]. |
| **Couraçado** | Inimigo resistente que ignora parte do dano. Veja [[inimigos/couracado]]. |
| **Eco** | Recurso permanente ganho ao fim da partida. Veja [[progressao/ecos]]. |
| **Errante** | Inimigo comum que persegue o personagem. Veja [[inimigos/inimigo-comum]]. |
| **Esquiva** | Deslocamento rápido com invulnerabilidade temporária. Veja [[controles/esquiva]]. |
| **Espreitador** | Inimigo rápido que tenta interceptar o jogador. Veja [[inimigos/espreitador]]. |
| **Horda** | Grupo de inimigos que surge ao redor do personagem. Veja [[combate/hordas]]. |
| **Isométrica** | Câmera vista de cima e na diagonal. |
| **Joystick flutuante** | Controle que aparece onde o dedo toca. Veja [[controles/joystick-flutuante]]. |
| **Leque** | Vários projéteis saindo juntos, com um pequeno ângulo entre eles. Veja [[melhorias/projetil-adicional]]. |
| **Lançador** | Inimigo que atira depois de um aviso visual. Veja [[inimigos/lancador]]. |
| **Lâmina orbital** | Arma com lâminas que giram ao redor do jogador. Veja [[armas/lamina-orbital]]. |
| **Level-up** | Subida de nível com escolha de arma ou melhoria. Veja [[progressao/level-up]]. |
| **Melhoria** | Bônus escolhido no level-up e válido só na partida. Veja [[melhorias]]. |
| **Melhoria permanente** | Bônus comprado com Ecos e mantido entre partidas. |
| **Nível (Nv.)** | Quanto o personagem evoluiu na partida atual. |
| **Nível de uma melhoria** | Quantas vezes ela foi escolhida, por exemplo 2/10. |
| **Orbe** | Cristal de experiência deixado por inimigos derrotados. Veja [[progressao/orbes-de-experiencia]]. |
| **Prévia** | Versão de teste do jogo e da Wiki, criada para cada Pull Request. Veja [[desenvolvimento/previas]]. |
| **Raio arcano** | Arma inicial de projéteis automáticos. Veja [[armas/arma-automatica]]. |
| **Sentinela do Eco** | Chefe que aparece aos dez minutos. Veja [[chefes/sentinela-do-eco]]. |
| **Survivors** | Gênero de jogo de hordas com ataque automático e melhorias a cada nível. |
| **Volátil** | Inimigo que prepara uma explosão de área. Veja [[inimigos/volatil]]. |
| **XP** | Experiência. Veja [[progressao/experiencia]]. |
| **Zona morta** | Área central do joystick em que movimentos pequenos são ignorados. |
