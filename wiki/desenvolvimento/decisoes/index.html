Decisões técnicas

Cada decisão registra o contexto, o que foi decidido e as consequências. Uma decisão antiga nunca é apagada: quando muda, uma nova decisão a substitui e explica o porquê. Elas vêm da pasta docs/decisoes/ do repositório.

  • 0001: Godot 4.7.2, GDScript, renderizador Compatibility e exportação Web sem threads
  • 0002: Projeto 100% em texto, com a partida montada em código
  • 0003: Objetos repetidos em arrays + MultiMesh, nunca um nó por objeto
  • 0004: Level-up usa a pausa nativa do Godot (`SceneTree.paused`)
  • 0005: Melhorias recalculadas a partir dos valores base
  • 0006: Publicação pelo branch `gh-pages`, com prévias por Pull Request
  • 0007: Wiki com gerador estático próprio em Python (só biblioteca padrão)
  • 0008: Duas IAs com papéis separados e o GitHub como fonte de verdade
  • 0009: Ferramentas de QA no CI (GDScript Toolkit e Playwright), sem custo e fora do jogo
  • 0010: Arquitetura do combate 0.3 (armas, inimigos, chefe, esquiva, resultados e progresso)
  • 0011: Build de produção sem a ponte de testes; build de QA só no CI
  • 0012: Gameplay da 0.4: estados em arrays, diretor de eventos, configurações próprias e som gerado no código
  • 0013: O EnemyManager ganha classes auxiliares, começando pelo desenho
